Sample Work: How I Research, Qualify, and Track Links

The clearest way to judge my work is to see the deliverable itself. Below are four demonstration projects in the exact format I use — sample data, real structure.

Please read this first: every project on this page is a sample / demo built with invented domain names and illustrative numbers. None of them is completed client work, and no result here should be read as a case study or a performance claim.
